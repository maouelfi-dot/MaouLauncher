Maou Launcher 2.10.7 (gabungan patch 2.10.5 + 2.10.6 + perbaikan Mabar)

Pilih SALAH SATU:
1) maou-2_10_7.patch
   Untuk repo yang SEKARANG (sudah berisi 2.10.5). Sudah termasuk isi patch 2.10.6.
   git apply maou-2_10_7.patch
2) maou-2_10_7-gabungan-dari-2.10.2.patch
   Gabungan 5+6+perbaikan, untuk repo yang masih 2.10.2.
3) folder files/  -> file lengkap hasil akhir, tinggal timpa ke repo (paling aman kalau patch gagal).

Yang diperbaiki:
- IP & port host otomatis akurat: IP ikut ditulis di paket siaran (bukan tebakan dari alamat pengirim),
  lalu IP:port dicek langsung (bisa disambungi) sebelum dipakai. Jaringan kuota/seluler diabaikan.
- Port dunia LAN dibaca dari 3 sumber (multicast, log game "Started serving on", /proc) + diverifikasi,
  dan berhenti diumumkan kalau dunia LAN ditutup.
- Entri "Mabar Hotspot" di daftar server otomatis berisi IP:port asli host (tidak perlu isi manual).
- Skin host tidak terlihat di HP WiFi: kunci multicast sekarang aktif sejak awal (sebelumnya baru aktif
  setelah host terdeteksi, jadi HP teman membuang siaran), unduh skin mencoba semua alamat calon + timeout lebih longgar.
- Menu Mabar: daftar IP hanya hotspot/WiFi (kuota disembunyikan) + tombol salin IP:PORT.
